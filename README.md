# Бот дедлайнов

Телеграм-бот, который понимает дедлайны, написанные обычным языком, и
напоминает о них заранее: за 3 дня, за день и за 3 часа. Сроки напоминаний
меняются командой.

Так выглядит разговор с ботом. Это настоящий вывод `python -m bot.demo`, тот
же код, что отвечает в Телеграме, только без сети:

```
> лаба 3 по физике до 25.10 18:00
Записал: Лаба 3 по физике
вс, 25 октября, 18:00 — через 4 дня.
Напомню за 3 дня, за день и за 3 часа.

> в пятницу к 9 утра коллоквиум
Записал: Коллоквиум
пт, 23 октября, 09:00 — послезавтра.
Напомню за день и за 3 часа.

> /list
На этой неделе
1. Коллоквиум — пт, 23 октября, 09:00, послезавтра
2. Лаба 3 по физике — вс, 25 октября, 18:00, через 4 дня

Позже
3. Курсач — ср, 4 ноября, через 2 недели
```

В напоминании есть кнопки **«Сделано»** и **«Через час»**.

## Что понимает

| Пишешь | Получается |
|---|---|
| `реферат до 10.01` | 10 января **следующего** года, если сейчас осень |
| `отчёт до 3 ноября` | 3 ноября, 23:59 |
| `курсач через 2 недели` | сегодня + 14 дней, 23:59 |
| `созвон через полчаса` | ровно через 30 минут |
| `тест завтра в 9` | завтра, 09:00 |
| `в 6 вечера презентация` | 18:00 |
| `в пятницу семинар` | ближайшая пятница; если сегодня пятница — следующая |
| `сдать долг в 16:00` | сегодня, а если 16:00 уже прошло — завтра |

Срок без времени означает «до конца дня», то есть 23:59. Число в названии
(«лаба **3**») не принимается за время: время распознаётся только как `18:00`
или как «в 9», «к 6 вечера».

## Устройство

```
bot/
  parse.py       разбор даты из текста — регулярки по очереди, остаток = название
  reminders.py   какие напоминания ещё имеют смысл; разбор «/remind 3д 1д 3ч»
  humanize.py    «пт, 23 октября», «через 3 дня», склонения
  storage.py     SQLite (aiosqlite): чаты, дедлайны, напоминания
  service.py     все ответы бота — без Телеграма
  scheduler.py   раз в 30 секунд отправляет то, что пора
  __main__.py    aiogram 3: команды и кнопки → вызовы service
```

Весь диалог живёт в `service.py` и возвращает `Reply(text, buttons)`.
Обработчики aiogram только переводят его в сообщения Телеграма. Поэтому 39 тестов
проверяют разговор целиком, без моков Telegram API.

Пара мест, где пришлось подумать:

- **Бот был выключен.** Если за это время накопилось несколько напоминаний по
  одному дедлайну, уйдёт только последнее. «За 3 дня» бессмысленно, когда уже пора «за 3 часа».
- **Пользователь заблокировал бота.** Ошибка отправки логируется, и рассылка
  идёт дальше. Один такой пользователь не останавливает напоминания всем остальным.
- **Дедлайн добавили поздно.** Если все напоминания уже в прошлом, остаётся одно
  «последнее» за 10 минут.
- **Время хранится в UTC.** Пояс задаётся на каждый чат (`/tz Asia/Yekaterinburg`),
  поэтому «в 10:00» для студента из Екатеринбурга значит его 10:00.
- **Чужие дедлайны не трогаются.** Кнопки содержат id дедлайна, но каждое
  действие проверяет `chat_id`. Подделанный callback ничего не сделает.

## Запуск

1. Получи токен у [@BotFather](https://t.me/BotFather).
2. `cp .env.example .env` и впиши токен в `.env`. Этот файл в `.gitignore`.
3. Запусти:

```bash
docker compose up -d --build
```

Без Docker:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
BOT_TOKEN=... python -m bot
pytest
```

## Стек

Python 3.12, aiogram 3, aiosqlite, pytest. GitHub Actions прогоняет тесты, демо
и сборку Docker-образа.
